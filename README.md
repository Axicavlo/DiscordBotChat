# 채팅봇

Discord 앱이나 웹을 열지 않고 사용하는 Windows·Android용 봇 채팅 프로그램입니다.
토큰 로그인 → 서버 선택 → 카테고리별 채널 선택 순서로 사용합니다. 모든 대화는 같은 창에서 전환됩니다.
모든 메시지는 **봇 계정**으로 전송됩니다. 개인 계정 및 개인 DM은 지원하지 않습니다.

이 문서는 현재 소스 기준입니다. 공개된 `v1.3.1` APK에는 이후 추가한 채팅 미디어 토글·애니메이션 등의 기능이 포함되어 있지 않습니다. 해당 기능을 사용하려면 현재 소스로 APK를 빌드해야 합니다.

## Discord 봇 준비

1. [Discord Developer Portal](https://discord.com/developers/applications)에서 애플리케이션을 생성하고 Bot 화면에서 봇 토큰을 발급합니다.
2. Bot → Privileged Gateway Intents → **Message Content Intent**를 켭니다.
3. Installation 또는 OAuth2 URL Generator에서 `bot`, `applications.commands` 범위로 서버에 초대합니다.
4. 필요한 채널에만 **View Channels / Read Message History / Send Messages / Embed Links / Attach Files** 권한을 부여합니다. 관리자 권한은 필요하지 않습니다.

## 주작기 토너먼트 추첨

`/펩시봇`을 입력하면 명령어 목록이 본인에게만 표시됩니다.

봇 앱을 연결한 상태에서 **Discord 서버 채널**에 `/주작기 시작 제목:치킨배`를 입력합니다.
슬래시 명령이 보이지 않으면 `applications.commands` 범위로 봇을 다시 초대하고 잠시 기다리세요.
앱의 일반 채팅 입력창에 명령어 문자열을 보내는 방식은 지원하지 않습니다.

- `/주작기 참가` 또는 모집 카드의 **참가 / 참가 취소** 버튼을 사용합니다. 채널당 활성 추첨은 하나이며 4~128명이 참가할 수 있습니다.
- 방장은 **참가자 관리**에서 서버 멤버를 여러 명 선택하여 추가하거나 제외할 수 있습니다. 봇 계정은 참가할 수 없습니다.
- 해당 채널에서 모집 또는 진행 중인 주작기가 있으면 새 방 생성을 막습니다. 다른 채널은 독립적으로 사용할 수 있습니다.
- 방장만 **시작 / 종료**를 누를 수 있으며, 시작 이후에는 참가 명단을 변경할 수 없습니다. 카드가 삭제되었어도 `/주작기 종료`로 종료할 수 있습니다.
- 성공 확인 메시지는 보내지 않습니다. 버튼은 별도의 ‘생각 중’ 응답 없이 처리하고, 실패했을 때만 안내합니다. 경기 시작 요청은 이미지 업로드 완료를 기다리지 않습니다.
- 매 경기 HP 6으로 시작하여 양쪽이 1~6 주사위를 굴립니다. 작은 눈이 나온 쪽이 차이만큼 피해를 받고, 같은 눈이면 피해 없이 계속합니다.
- 각 라운드 무작위 대진을 만들고 홀수면 한 명이 무작위 부전승합니다. 가능한 경우 이전 부전승자를 제외합니다.
- 3명이 남으면 직전 라운드 탈락자끼리 패자부활전을 치러 한 명을 복귀시키고, 4명으로 준결승을 진행합니다.
- **3·4위전 → 결승전 → 최종 순위** 순서입니다. 1~4위는 개별 순위, 나머지는 같은 본선 라운드 탈락자끼리 공동 순위입니다.
- 대결 이미지는 두 참가자를 좌우에 고정합니다. 한 경기의 실제 주사위 결과를 미리 계산하여 주사위 굴림부터 모든 턴의 체력 감소까지 GIF 하나로 재생합니다. 같은 경기 안에서는 턴이 바뀌어도 이미지 파일을 교체하지 않습니다. 다음 대결로 넘어갈 때 새 GIF를 올립니다.
- 카운트다운 3·2·1은 GIF 안에서 0.3초 간격으로 표시합니다. 주사위는 굴리는 동안 `?`를 유지하다가 실제 결과에 바뀝니다. 진행 중 공개 임베드는 대진 정보와 GIF만 보여주며 턴마다 수정하지 않습니다.
- 주사위·피해·승패 기록은 계속 저장하고 **경기 기록** 버튼을 누른 사람에게만 표시합니다. 다음 대결·최종 순위·종료·오류로 상태가 바뀔 때 공개 메시지를 갱신합니다.
- 결과 공개 후 피해 칸은 초록 → 빨강 → 회색 → 빈칸으로 0.3초씩 전환하며, 결과 후 다음 턴까지는 1.5초입니다(주사위 연출 포함 한 턴 약 2.4초). 예정된 주사위 결과와 공개한 턴 위치를 저장하여 재연결 시 같은 결과로 이어갑니다. 매우 긴 경기는 메모리 사용을 제한하기 위해 최대 32턴씩 GIF를 나눕니다.
- 대진표는 앞 3글자 닉네임과 연결선을 사용합니다. 축약 이름이 겹치면 숫자로 구분하고, 전체 대진·3·4위전·부전승 기록을 PNG 한 장에 표시합니다. 인원이 많으면 이미지를 확대해서 확인하세요.
- 모집·주사위·HP·최종 결과는 **같은 공개 메시지 하나를 갱신**합니다. 대진표·경기 기록·전체 순위와 참가 확인·관리는 누른 사람에게만 표시합니다.

앱을 종료하면 진행이 멈추며, 같은 기기에서 다시 연결하면 저장된 경기부터 이어집니다.
Windows 상태는 `%LOCALAPPDATA%\DiscordBotChat`, Android 상태는 앱 내부 저장소에 보관합니다. 토큰은 이 파일에 저장하지 않습니다.
상태는 기기 사이에 동기화되지 않으므로 **같은 봇 토큰은 한 기기에서만 실행**하세요. 같은 Windows 기기에서 중복 실행하면 추가 앱의 추첨 기능은 비활성화됩니다.
메시지 삭제·권한 부족 등으로 진행이 멈추면 원인을 해결하고 앱을 다시 연결하세요.
실패 시 오류 종류와 코드 위치를 안내하며, Windows의 `%LOCALAPPDATA%\DiscordBotChat\tournament-errors.log`에도 기록합니다. 오류 기록에는 토큰·URL·예외 원문을 저장하지 않습니다.

## 숫자야구

봇 앱을 연결한 뒤 **Discord 서버 채널**에서 `/숫자야구`를 입력하면 방이 열립니다. 채널당 한 방에서 최대 25명이 플레이할 수 있습니다.

| 명령어 | 동작 |
| --- | --- |
| `/숫자야구` 또는 `/숫자야구 중복가능:n` | 정답과 입력 모두 같은 숫자를 한 번씩만 쓸 수 있습니다. |
| `/숫자야구 중복가능:y` | 정답과 입력 모두 같은 숫자를 여러 번 쓸 수 있습니다. |

1. 방장은 자동으로 참가하고, 다른 사람은 **참가** 버튼을 누릅니다. 방장이 **시작**을 누르거나 방을 연 지 60초가 지나면 게임이 시작됩니다.
2. 참가자는 **숫자 입력**을 눌러 네 자리 숫자를 제출합니다. `0372`처럼 첫 자리에 0을 쓸 수 있습니다. 첫 시도 후에는 개인 결과 임베드의 버튼으로 계속 입력할 수 있고, 같은 임베드에 시도 기록이 쌓입니다.
3. 숫자와 위치가 모두 맞으면 스트라이크(S), 숫자만 맞으면 볼(B)입니다. 스트라이크부터 제외하고 남은 숫자를 한 번씩 짝지어 볼을 셉니다. 예를 들어 정답이 `1977`이고 입력이 `1179`이면 `2S 1B`입니다.
4. 각 참가자는 최대 9번 시도합니다. 메인 임베드에는 정답을 맞힌 턴 수 또는 실패가 표시됩니다. 모두 완료하거나 시작 후 10분이 지나면 정답이 공개됩니다. 방장이 진행 중 **종료**를 누르면 즉시 정답을 공개하며, 시간 초과 또는 방장 종료 시 미완료자는 실패 처리됩니다. 시작 전 **종료**는 모집을 닫습니다.

숫자야구 방은 봇 앱을 재시작하면 초기화됩니다.

## 실행

### Android APK 실행

1. [GitHub Releases](https://github.com/Axicavlo/DiscordBotChat/releases)에서 `ChatBot-버전.apk`를 휴대폰에 내려받아 설치합니다.
2. 앱을 열고 봇 토큰을 입력해 연결합니다. 알림 권한을 허용하면 연결 상태와 종료 버튼을 알림에서 확인할 수 있습니다.
3. 서버·채널을 선택하고 메시지를 전송합니다. 메시지를 길게 누르면 답장·사용자 멘션·복사 메뉴가 열리고, 연결된 봇이 보낸 메시지에는 편집·삭제도 표시됩니다.

Android 7.0 이상인 64비트 ARM 휴대폰과 x86_64 에뮬레이터를 대상으로 합니다.
별도 서버 없이 휴대폰이 Discord에 직접 연결합니다. 홈 버튼으로 내려도 연결 서비스를 유지하며,
절전·네트워크 변경으로 연결이 끊기면 재연결합니다. Android가 앱을 강제 종료하거나 사용자가 연결을 종료하면 봇도 오프라인이 됩니다.
앱 복귀 시 선택한 채널의 최근 메시지를 다시 불러옵니다. 24시간 연결 유지는 보장하지 않습니다.

### EXE 실행

1. 빌드된 `ChatBot.exe`를 더블클릭합니다. 이 프로젝트에서 빌드한 파일은 `dist\ChatBot.exe`에 있습니다.
2. 첫 실행 시 봇 토큰을 입력하고 **연결하기**를 누릅니다.
3. 연결 후 서버와 채널을 선택해 대화합니다.

Python 설치나 배치파일 실행은 필요 없습니다. 이미지와 실행 라이브러리가 포함되어 있어 EXE 파일만 옮겨 실행할 수 있습니다.
EXE는 Git에 포함하지 않으므로 소스만 내려받은 경우 아래 **EXE 빌드** 과정을 먼저 진행하세요.

### Python 실행

Python 3.11 이상(Tkinter 포함)이 필요합니다.
소스에서 Windows 한글 조합 표시를 사용하려면 C++ 빌드 도구가 있는 환경에서
`.venv\Scripts\python.exe tools\build_ime.py`를 한 번 실행하세요. 빌드 전에는 Tk 기본 한글 입력을 사용합니다.

1. 최초 한 번 `setup.bat`을 실행해 가상 환경과 discord.py를 설치합니다.
2. `start.bat`을 실행합니다. 별도 콘솔 창 없이 기본 창이 열립니다.
3. 봇 토큰을 입력하고 연결합니다.

### EXE 빌드

Windows에서 Python 3.11 이상(Tkinter 포함)을 설치한 뒤 진행합니다. 최초 환경 구성과 빌드 도구 설치에는 인터넷 연결이 필요합니다.
Windows EXE 빌드에는 Visual Studio의 C++ x64 빌드 도구와 Windows SDK도 필요합니다.
`build_exe.bat`은 한글 조합 표시용 `native/ime_preview.c`를 DLL로 빌드해 EXE에 포함합니다.
Windows 메시지 콜백은 Python·Tk를 호출하지 않으며, 조합 중 글자 표시는 Tk 이벤트 루프에서 갱신합니다.

1. 최초 한 번 `setup.bat`을 실행합니다.
2. `build_exe.bat`을 실행합니다.
3. 빌드 완료 후 `dist\ChatBot.exe`를 실행합니다.

빌드 스크립트는 `requirements-build.txt`에 지정한 PyInstaller를 설치하고 콘솔 창 없는 단일 EXE를 생성합니다.
코드를 수정했다면 EXE를 종료한 뒤 다시 빌드하세요. 토큰 파일은 빌드에 포함하지 않습니다.

### APK 빌드

Windows에서 `setup.bat`으로 Python 환경을 준비한 뒤 `build_apk.bat`을 실행합니다.
최초 실행은 JDK 17·Python 3.12·Gradle·Android SDK와 Python 패키지를 `.build-tools`에 내려받으므로 시간이 걸립니다.
빌드 과정에서 Android SDK 라이선스에 동의합니다. WSL이나 Android Studio 설치는 필요하지 않으며 시스템 기본 Java를 변경하지 않습니다.

완료되면 `dist\ChatBot.apk`와 `dist\ChatBot-버전.apk`가 생성됩니다.
현재 추출 도구는 직접 설치 가능한 디버그 서명 APK를 만듭니다. 업데이트 설치에는 같은 서명 키가 필요하므로
`.build-tools\android-user`의 서명 키를 보관하세요. Google Play 배포용 릴리스 서명은 별도 설정이 필요합니다.

### 공통 기능과 버전 관리

| 파일 | 역할 |
| --- | --- |
| `chatbot_core/__init__.py` | 양쪽 앱이 함께 사용하는 Discord 연결·메시지·답장·재연결 로직 |
| `chatbot_core/version.py` | 공통 버전 `VERSION`과 Android 업데이트 번호 `VERSION_CODE` |
| `chatbot_core/media.py` | 채팅 이미지·이모지·스티커·임베드 추출과 Windows 미디어 배치 |
| `app.py` | 기존 Windows Tkinter 화면·Windows 토큰 저장 |
| `desktop_images.py` | Windows 이미지 다운로드·캐시·애니메이션 프레임 처리 |
| `android/` | Android 화면·연결 서비스·Android 토큰 저장 |
| `build_exe.bat` | 현재 공통 코드를 포함한 Windows EXE 생성 |
| `build_apk.bat` | 현재 공통 코드를 포함한 Android APK 생성 |

공통 기능을 수정한 뒤 원하는 빌드 도구를 실행하면 해당 플랫폼의 프로그램이 생성됩니다.
배포 시 `VERSION`과 `VERSION_CODE`를 함께 올리고 양쪽을 다시 빌드하세요.
화면·운영체제별 기능은 각각 구현하며, 빌드 도구는 설치된 앱을 자동 업데이트하지 않습니다.

## 사용 방법

메시지 작성자·답장·멘션 목록은 서버 닉네임을 우선 표시합니다. 서버 닉네임이 없거나 조회할 수 없으면 Discord 표시 이름을 사용합니다. 서버별 닉네임 조회 결과는 잠시 캐시하며, 멘션 전송에는 사용자 ID를 사용합니다.
서버 목록에는 서버 아이콘을, 채팅에는 서버별 사용자 프로필 이미지를 우선 표시합니다. 서버별 프로필이 없으면 일반 프로필·기본 아바타를 사용하며, 이미지를 불러오지 못하면 글자 아이콘을 유지합니다.

- 맨 왼쪽 서버 아이콘을 클릭하고, 카테고리별 채널 목록에서 채널을 선택합니다.
- 같은 창에서 대화를 전환하며 채널별 초안과 답장 대상은 유지됩니다.
- Windows에서는 채널 목록 우상단의 왼쪽 화살표로 목록을 접고, 접힌 위치의 오른쪽 화살표로 펼칩니다.
- 맨 위 홈 아이콘에서 토큰을 변경해 다른 봇으로 연결할 수 있습니다. 봇 변경 시 기존 대화와 초안은 초기화됩니다.
- 메시지는 전송 버튼으로 보냅니다. Windows에서는 Enter로도 보내며, Shift+Enter 또는 Alt+Enter는 줄바꿈입니다.
- Windows에서는 메시지 내용을 드래그해 일부만 선택하고 `Ctrl+C` 또는 우클릭 메뉴의 **선택 영역 복사**로 복사할 수 있습니다.
- Windows·Android 모두 입력창에서 `@`를 입력하면 채팅 영역 안에 사용자 목록이 오버레이로 나타납니다. 닉네임을 이어 입력해 검색하고 목록에서 선택하면 실제 사용자 멘션으로 바뀝니다. 공백을 입력하거나 `@`를 지우면 목록이 닫힙니다. Windows에서는 방향키와 Enter로도 선택할 수 있습니다.

### 메시지 편집·삭제

- Windows는 메시지를 **우클릭**, Android는 **길게 누르기**로 메뉴를 엽니다.
- 현재 연결한 봇이 보낸 메시지에만 **편집 / 삭제**가 표시됩니다. 다른 사용자나 다른 봇의 메시지는 편집·삭제할 수 없습니다.
- **편집**을 선택하면 해당 말풍선이 입력창으로 바뀝니다. **저장 / 취소** 버튼을 사용하며, Enter는 저장, Shift+Enter 또는 Alt+Enter는 줄바꿈입니다. Android 소프트키보드에서는 완료·전송 동작으로 저장할 수도 있습니다.
- 본문은 공백이 아닌 1~2,000자로 입력합니다. 기존 첨부파일과 임베드는 유지하고, 편집으로 멘션 알림을 다시 보내지 않습니다. 저장에 실패하면 입력 내용을 유지합니다.
- 수정된 메시지는 말풍선 옆 시간 위에 작은 **편집됨** 표시가 붙습니다.
- **삭제**는 확인창에서 승인한 뒤 처리하며, 삭제한 메시지는 복구할 수 없습니다.

### 채팅 이미지·이모지·스티커·임베드

- **이미지 스위치는 앱을 열 때마다 기본 꺼짐**입니다. Windows는 왼쪽 채널 목록 하단의 연결 상태 오른쪽, Android는 상단 연결 상태 오른쪽에 있습니다.
- 스위치를 켜면 현재 채팅의 첨부 이미지, 지원하는 이미지 링크, 커스텀 이모지, 스티커와 임베드 내용을 표시합니다. 끄면 해당 미디어를 숨기고 **미디어 숨김** 표식을 남깁니다. 일반 본문과 유니코드 이모지, 서버 아이콘·프로필 이미지는 유지됩니다.
- 꺼진 상태에서는 채팅 미디어를 새로 다운로드하지 않습니다. 켜면 화면에 보이는 메시지 주변부터 받아 캐시하며, 같은 이미지는 다운로드를 재사용합니다. 반복해서 보낸 이모지는 보낸 개수대로 표시하고 가로로 배치합니다.
- 이미지의 원래 비율을 유지합니다. Windows의 일반 이미지 미리보기는 최대 320×220, 스티커·확대 이모지는 최대 160×160 범위에 맞춥니다. 작은 원본을 임의로 키우지 않으며, 원본 자체의 낮은 해상도를 복원하지는 않습니다.
- 원본 CDN 이미지를 불러오지 못하면 메시지에 포함된 Discord 프록시 주소로 다시 시도합니다. 원본과 프록시가 같은 이미지이면 중복으로 표시하지 않습니다.
- Windows는 GIF·APNG·움직이는 WebP를 프레임 시간에 맞춰 재생합니다. 이미지 스위치를 끄거나 채팅을 숨기면 재생을 멈춥니다. 긴 애니메이션은 프레임 수·메모리 제한으로 일부 프레임까지만 재생될 수 있습니다.
- Android 9.0 이상은 GIF·움직이는 WebP 재생을 지원합니다. Android 7.0~8.1은 정지 미리보기이며, Android의 APNG 애니메이션은 보장하지 않습니다. Lottie 형식의 스티커는 지원하지 않습니다.
- Windows에서는 이미지 로딩 중에도 읽던 메시지의 스크롤 위치를 유지합니다. 위로 스크롤한 상태에서는 새 메시지가 와도 내려가지 않으며, 맨 아래에 있을 때만 새 메시지를 따라갑니다.

미리보기는 메시지당 최대 20개이며, 이미지당 다운로드 용량·크기 제한이 있습니다. Discord CDN·이미지 프록시와 지원 CDN의 이미지만 처리하며 모든 외부 이미지 주소를 지원하지는 않습니다. 원본 확대 창, 동영상 재생과 첨부파일 업로드는 지원하지 않습니다.

## 토큰 저장

연결에 성공한 마지막 토큰은 Windows 사용자 계정으로 암호화해 저장하고 다음 실행 때 자동으로 채웁니다. 연결 시 입력란은 지워집니다.

| 실행 방식 | 저장 위치 |
| --- | --- |
| EXE | `%LOCALAPPDATA%\DiscordChatBot\.bot-token.dat` |
| Python | `app.py`와 같은 폴더의 `.bot-token.dat` |
| Android | 앱 내부 저장소 (Android Keystore의 AES-GCM 키로 암호화) |

실행 방식마다 토큰을 따로 저장하므로 다른 방식으로 전환할 때 토큰을 한 번 입력해야 합니다.
저장 정보를 지우려면 프로그램을 종료한 후 해당 파일을 삭제하세요.
Android는 앱의 **토큰 삭제** 버튼으로 저장 정보를 삭제합니다. 토큰은 연결 성공 후에만 저장합니다.

토큰은 다른 사람에게 공유하거나 채팅에 붙여넣지 마세요. 선택적으로 `DISCORD_BOT_TOKEN` 환경 변수도 사용할 수 있습니다.
프로그램을 종료하면 봇 연결도 종료됩니다. 인터넷 연결은 필요합니다.

## 동작 범위

- 서버 텍스트 채널: 최근 100개, 실시간 수신, 전송, 수정·삭제 반영. 창에는 최근 500개를 유지합니다.
- 이미지 첨부는 이미지 스위치로 미리보기를 켤 수 있으며, 그 외 첨부파일은 URL로 표시합니다. 업로드·스레드·포럼·음성 채널은 지원하지 않습니다.
- 사용자 멘션과 답장은 항상 알림을 요청합니다. 전체·역할 멘션 알림은 비활성화되어 있습니다.
- 채널 권한 변경 후에는 목록 새로고침을 누르세요.
- 네트워크가 복구되면 Discord 연결을 자동 재시도합니다. 맨 왼쪽 서버 목록 하단에 고정된 새로고침 아이콘은 서버·채널 목록과 현재 대화의 최근 기록을 다시 불러옵니다.
- 토큰 및 Intent 오류가 나오면 설정을 수정하고 다시 연결합니다.

문제 확인용 실행: `.venv\Scripts\python.exe app.py`

공식 참고: [discord.py Intents 안내](https://discordpy.readthedocs.io/en/stable/intents.html)
